Featured / Accelerated computing

FlashServe-4bit

I built an INT4 inference pipeline for a 3B-parameter transformer and implemented fused dequantization kernels in Triton. The question was how much GPU memory I could save without giving up too much model accuracy.

I profiled prefill, decoding, KV-cache allocation and concurrent workloads on an NVIDIA L4. Compared with BF16, the INT4 pipeline increased generation throughput while keeping task-accuracy degradation below one percentage point on 800 fixed prompts.

CUDA · Triton · vLLM · PyTorch · AWQ · NVIDIA L4

GPU dispatch

Six jobs, three identical simulated GPU lanes. Assign every job and minimize the time when the last lane finishes. Can you find the optimal schedule?

Concept: makespan, load balancing and scheduling heuristics. Each job runs to completion; durations are simulated.
